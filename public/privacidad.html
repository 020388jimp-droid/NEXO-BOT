Aviso de privacidad

Última actualización: octubre de 2026

NEXO BOT es un asistente virtual que atiende conversaciones de WhatsApp y la demo web de este sitio. Este aviso explica qué datos tratamos y para qué.

1. Datos que recopilamos

  • Número de teléfono de WhatsApp y nombre de perfil público.
  • El contenido de los mensajes que envías al asistente.
  • Los datos que proporcionas para agendar una cita: nombre, servicio, fecha y hora.
  • En la demo web, un identificador de sesión anónimo guardado en tu navegador.

2. Para qué los usamos

  • Responder tus preguntas y dar seguimiento a la conversación.
  • Agendar, confirmar o cancelar citas.
  • Mejorar la calidad de las respuestas y detectar fallos del servicio.

3. Con quién se comparten

Para funcionar, el bot utiliza proveedores tecnológicos que procesan los mensajes: Meta (WhatsApp Cloud API) para el envío y recepción de mensajes, y Google Cloud (Gemini, Cloud Run y Firestore) para generar respuestas y almacenar la información. No vendemos ni compartimos tus datos con terceros para publicidad.

4. Conservación

Las conversaciones se conservan mientras sean necesarias para atenderte y, como máximo, durante 12 meses. Los datos de citas se conservan mientras la cita esté activa y por el tiempo necesario para fines administrativos.

5. Tus derechos

Puedes solicitar acceso, corrección o eliminación de tus datos escribiendo a hola@dentalnova.mx. Responderemos en un plazo máximo de 20 días hábiles.

Nota: esta demo usa datos de ejemplo de un negocio ficticio. Si despliegas NEXO BOT para tu propia empresa, sustituye estos textos y el correo de contacto por los datos reales de tu negocio.

6. Seguridad

Las comunicaciones viajan cifradas mediante HTTPS. El acceso a la base de datos está restringido a la cuenta de servicio del proyecto en Google Cloud.
